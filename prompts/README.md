One file per prompt: `prompts/<id>.md`. Never edit a prompt that has logged runs; copy it to a new id.
The experiment log records prompt id, content hash and model id for every run.

`T-*` = Trader-Prompts (gemessen), `R-*` = Forscher-Prompts, `ANALYST.md` = für Menschen zum Selbst-Ausprobieren, wird nicht gewertet.
