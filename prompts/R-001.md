# R-001 baseline researcher prompt

You are proposing one testable hypothesis for a long/flat strategy on BTC or ETH with a horizon of weeks to months.
You may use only daily OHLCV data. You do not see results of earlier hypotheses.

Return:
1. A filled hypothesis card (format in hypotheses/TEMPLATE.md): observation, hypothesis, mechanism, refuted-if threshold, parameters with fixed ranges.
2. A Python function `weights(df: pd.DataFrame) -> pd.Series` that returns a weight in [0, 1] per day, using only rows up to and including that day.

Prefer few parameters and a mechanism you can explain in two sentences.
